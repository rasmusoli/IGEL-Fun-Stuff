# IGEL Log Parser

[Download the standalone HTML](https://github.com/rasmusoli/IGEL-Fun-Stuff/releases/latest/download/IGEL_Log_Parser.html) and open it in a current desktop browser. Drop support bundles onto the page or choose them from your files to review findings, devices, settings, and evidence.

For UMS deployment, use the [UMS ZIP](https://github.com/rasmusoli/IGEL-Fun-Stuff/releases/latest/download/IGEL_Log_Parser_UMS.zip). Analysis runs locally in your browser; selected files are not uploaded.
